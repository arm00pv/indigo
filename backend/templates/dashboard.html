Recovery Options

If you have lost your Admin API Key, you cannot log in. To reset the system:

  1. Set the environment variable RESET_DB=true in your deployment configuration.
  2. Redeploy the application.
  3. The database will be wiped, and the Setup Wizard will appear.
  4. Remove the RESET_DB variable immediately after setup to prevent data loss.
Warning: This action deletes ALL user data and keys.
